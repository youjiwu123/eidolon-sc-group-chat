# 杜野凛世 ・ 人设补遗草稿（pilot）

> 给 `characters/sheets/rinze.md` 的**追加候选**（只加不改）。每条都附语料原句，收不收由人判断。
> 流程：分层抽样她的台词 → `deepseek-flash` 归纳 → 原句回查（不通过就丢）→ 与现有 sheet 对照。原 sheet 未改动。

## 样本与口径

- **语料**：`sc-archive/story_json` 5,611 集剧本，`.scratch/schedule/extract.py` 展平成 249,483 行；归属规则同 `characters/schedules.stats.md`「方法与口径」：她出场、剧本行数与 DB 对齐的集，说话人是她的 `speakers`。可用 358 集 / 3,541 句候选。
- **抽样**：**300 句**，来自 185 集、132 个不同 bg；按剧情类型轮转（P卡剧情 59 / S卡剧情 58 / 活动剧情 58 / 培育剧情 58 / 特别剧情 58 / 主页剧情 9），单集 ≤3 句、单 bg ≤16.0%（上限 25%）；先去掉 <8 字（1,258 句）与纯拟声/语气词（447 句）。
- **背景分布**（前 8）：事务所休息室 22.7%、画面外（特写/UI/走廊） 16.3%、和室 3.7%、白屏（无画面） 3.3%、说不准（纯天空/明暗） 3.0%、公园 3.0%、公寓客厅 2.7%、展望台 2.7%。
- **模型**：`deepseek-flash`（chat-completions，reasoning effort `high`），`forbid_calls=True` 流式，每角色 1 次调用（本次 37.2s，无重试），2026-10-26。
- **引文回查**：模型回 28 条，28 条原句都在她的样本里逐字出现（剔除 0 条）。normalize 只去掉空白、换行和提示词里代表换行的「／」。全部 249,483 行里只有 5 行带方括号（都是「［投票はこちら］」这类游戏指示），没有 `[softly]` 这类 delivery cue，所以没有可剥的语气标注。
- **复现**：脚本在 `.scratch/persona/`（`sample.py` → `analyze.py` → `verify.py` → `counts.py` → `render.py`），样本 seed `20261028`，模型的原始回答在 `llm_rinze.raw.txt`。
- **JSON 形状**：照模板要 speech / address / emotion / topics / avoid / habits；只有一处扩展——`avoid` 也返回 `{trait, quote}`（模板里是字符串数组），这样「她不会说的话」同样有原句可查。
- **数字佐证**：下面的命中率用同一批台词在全语料 / 300 句样本上重算，用来检验「常」字。样本按剧情类型配平，**样本内比例不代表语料比例**，判断频率看全语料那列。

## 已有，不必加

模型给的 28 条里 13 条是 sheet 已经写到的：「でございます」、省略号、「凛世」自称、「はい……」开头、「でしょうか」、「ふふ」、「申し訳ございません」、物语和和歌、演戏、折纸、不用粗暴的命令式、称呼（プロデューサーさま等）。

## 不建议加入

- **「夜更かし」**：『夜更かしを……いたしました……』全语料 3 句（0.1%），是一集的经历。
- **「月／夜空」**：『たくさんの……月が……』全语料 7 句（0.1%），单集写景，不是她会主动聊的话题。
- **「细细描述食物味道」**：『いちごの……味がいたします……』全语料 4 句（0.1%）。

## 这个方法测不到的东西

- **语气和语速**：剧本只有文字，没有重音、停顿长度、音量；「……」到底是迟疑还是平静，只能从上下文猜。
- **对谁说的**：样本只有她自己的台词，没有对象标注；称呼、普通体/敬语体的切换对象只能事后查前后句（这次只抽查了真乃的普通体），没做全量标注。
- **delivery cue**：这份语料没有 `[softly]` 之类的语气标记（small-talk 的 `ja` 也没有），所以「轻声」「笑着说」这类信息只能从措辞推。
- **非台词信息**：立绘表情、动作、BGM、背景明暗都没进样本；同一句话配什么表情，这里看不到。
