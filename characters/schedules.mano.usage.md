# 场景使用统计（2026-10 版）

总场景 84。口径：`characters/schedules.mano.week.draft.toml` 的 slots / pools / holidays / events，
加上 `characters/holidays.toml` 的 32 条日历。`sky`（说不准）是判断模型挑不出地点时的兜底，
故意不参与随机。

| 规则 | 条数 | 覆盖场景 |
|---|---:|---:|
| 固定槽位 `[[slots]]` | 65 | 34 |
| 随机池 `[[pools]]`（日常 any / 夜间 night） | 2 | 37 |
| 事件 `[[events]]` | 17 | 19 |
| 节日覆盖 `[[holidays]]` | 32 | 28 |
| 去重合计 | | **83 / 84** |

## 只在事件里出现（6）

机场、酒吧、保龄球馆、诊察室、医院走廊、居酒屋 —— 都要专门去、或者不该是日常，
所以不进池子，只在事件里出现（居酒屋/酒吧还限定「忘年会 + 夜里」，她只喝ウーロン茶）。

## 只在节日里出现（1）

银杏道 —— 秋分の日 / 文化の日 / 勤劳感谢日 / 红叶狩り 四条节日覆盖。季节限定，不进池子。

## 只在随机池里出现（27）

小巷、美术室、面包店、浴室、书店、车里、十字路口、宿舍、电竞房、快餐店、杂货店、阶梯教室、
图书室、会议室、事务所大楼、事务所走廊、事务所前台、宠物店、铁路道口、住宅街、天台、校门、
澡堂、车站、车站大厅、地铁通道、自动贩卖机 —— 固定槽位排不进、但「她今天在别处」完全说得通的地方。

## 槽位里有、事件/节日也会用（15）

咖啡店、她的家、家里的客厅、厨房、事务所休息室、商场、公园、夜晚的公园、家庭餐厅、河堤、
商店街、石板路、练习室、超市、电车上。

## 没被用到的（1）

`sky` 说不准 —— 兜底场景。

> 旧版这里是「37/84」：那是只有固定槽位时的口径。加了随机池和节日覆盖之后是 83/84，
> 唯一剩下的就是兜底用的 `sky`。逐条数字跑 `.scratch/schedule/simulate.py`（2026 全年）。
